xtra provides a growing collection of extra utility functions for R. It
currently includes:

- `read_excel_multi_headers()` reads Excel files with multiple header
  rows and merged cells.
- `save_plot()` saves any plot to disk.
- `docx_add_img()` adds images with optional captioning to Word
  documents.

## Installation

You can install the development version of xtra from
[GitHub](https://github.com/NourEdinDarwish/xtra) with:

``` r
# install.packages("pak")
pak::pak("NourEdinDarwish/xtra")
```
